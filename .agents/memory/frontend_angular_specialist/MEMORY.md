# Frontend Angular Specialist Memory — FOSS Training

Index of Angular 22 component architectures, signal patterns, Tailwind UI components, and Vitest test practices.

## Initial Knowledge
- **Stack**: Angular 22.1.0, TypeScript 6.0, Tailwind CSS, Vitest 4.0.8, JSDOM.
- **Component Architecture**: 100% standalone components (`standalone: true`).
- **Reactive Model**: Signals first (`signal`, `computed`, `effect`, `input`, `output`).
- **Control Flow**: Modern `@if`, `@for (...; track ...)`, `@switch` syntax.
- **UI System**: Dark-themed glassmorphism (`backdrop-blur-md`, `bg-slate-900/80`, `border-slate-800/60`).
- **Testing Command**: `npm test -- --watch=false` for non-interactive test execution.
- **API Types**: Synchronized via `npm run codegen:api`.
